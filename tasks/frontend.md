# Frontend — статус и распределение (2026-09-05)

Живая версия: **https://skytime.daniel.crazedns.ru** (реальный бэкенд).
Локальный мок для быстрой разработки без бэкенда: `flutter build web
--release` без `--dart-define`, раздать `build/web` любым статик-сервером
(порт 2030 — уже установившаяся у команды конвенция).

Контракт с бэкендом — [`backend.md`](backend.md). Критерии оценки —
[`../docs/KNOWLEDGE_BASE.md`](../docs/KNOWLEDGE_BASE.md#2-критерии-оценки--100-баллов).

## ✅ Готово и задеплоено

- **Лендинг на корне** (`/`) — приветствие, встроенное интерактивное
  окошко-превью карты (те же данные, что и полноразмерная карта) с
  временной шкалой, описание функций и шкалы Z-score. Полноразмерная
  карта — на `/map`.
- **Карта** (`/map`) — спутниковый слой (Esri World Imagery), полигоны
  цветом по Z-score-статусу, временной слайдер, автопоиск контуров в
  области ("Найти контуры полей в этой области" — теперь работает и на
  реальном бэкенде через `region_search.py`, см. `backend.md`).
- **Рисование полигона** — входится только из личного кабинета (кнопка
  "Создать полигон" проверяет вход), на самой карте отдельной кнопки
  "нарисовать" нет — режим включается автоматически. Undo/redo точек
  (Ctrl+Z/Ctrl+Y, а также Cmd на Mac). Обязательное название полигона
  перед сохранением (диалог).
- **Личный кабинет** (`/account`) — список своих полигонов (карточки:
  цветная полоска, реальная площадь по формуле шнурков, культура,
  статус-таблетка по актуальному Z-score), быстрые действия, вход/выход.
- **Полноценный CRUD** — создание, просмотр, редактирование
  (подпись/культура), удаление своего полигона. Шеринг ссылкой (просмотр
  публичный, без входа).
- **Auth-флоу** — регистрация → подтверждение почты → вход, с
  предзаполненным демо-аккаунтом в моке (`demo@skytime.dev` /
  `demo1234`) и подсказкой-кнопкой "Подставить" на экране входа. Глазок
  видимости пароля на входе/регистрации.
- **Дашборд-навигация** (2026-09-05, по референсу `../style/`) —
  постоянный левый сайдбар на широких экранах (≥900px), обёртка
  `widgets/dashboard_shell.dart`: разделы Карта/Участки (рабочие) и
  Аналитика/Уведомления/Отчёты/Настройки (заглушки со снэкбаром "ещё не
  готово", не тихий переход в никуда). На узких экранах — без сайдбара,
  как раньше.
- **Чистые URL** (`usePathUrlStrategy()`) — все экраны видны в адресной
  строке (`/map`, `/account`, `/polygon/:id`, `/login`, ...), без `#/`.
- **Кнопки, недоступные без входа, зачёркнуты** ("Создать полигон",
  редактировать/удалить чужой/неавторизованный полигон) — кликабельны и
  ведут на `/login`, а не просто задизейблены молча.
- **SkyTime-брендинг** — палитра navy/cream/teal/lime(+violet/pink),
  логотип, favicon/иконки под концепт "спутник+часы".
- **Производительность**: параллельная загрузка временных рядов
  (`Future.wait` вместо последовательных `await` в цикле) — на реальном
  бэкенде с 39 полигонами последовательная загрузка давала заметную
  задержку карты, исправлено 2026-09-05.
- Комментарии в коде — на русском (требование критериев).

## ⚠️ Известные ограничения (осознанные, не баги)

- **Область поиска реальных фото/контуров** зависит от того, есть ли
  открытые OSM-контуры в выбранном регионе — это ограничение бэкенда
  (`region_search.py`), не фронта.
- **Live-анализ произвольно нарисованного полигона** (реальные
  спутниковые данные для НЕ-соревновательных координат) пока не работает
  — блокируется отсутствием GEE-доступа на бэкенде (см. `backend.md`).
  Нарисованный полигон сохраняется и виден, но его временной ряд сейчас
  либо пуст, либо мок-сгенерированный, в зависимости от реализации на
  бэке на момент чтения этого файла — проверить `POST /timeseries/
  {id}/upload`-флоу перед демо.
- **Локальный мок и реальный бэкенд теперь визуально расходятся по
  количеству полигонов на карте по умолчанию** (это осознанно
  синхронизировано: оба показывают только свои/custom полигоны по
  умолчанию, готовые контуры соревнования скрыты, пока не найдены через
  поиск региона или не открыты по прямой ссылке) — если увидите
  расхождение, сверьтесь с `map_screen.dart`/`landing_screen.dart`
  (`_visiblePolygons`/`.where((p) => p.isCustom)`), это не баг.
