# ML-отчёт: восстановление NDVI и детекция аномалий

## Гипотеза

Если при восстановлении скрытого `primary_ndvi` использовать не только два
ближайших наблюдения, но также сезонность, климатологическую норму, независимые
ряды Sentinel-2/Landsat/MODIS и историю того же полигона, то модель-корректор
снизит RMSE относительно простой интерполяции. Наибольший эффект ожидается для
нерегулярных и длинных пропусков, где два соседа хуже описывают форму сезона.

Критерий подтверждения: OOF RMSE должен быть ниже baseline на большинстве
GroupKFold-фолдов, причём полигоны в обучении и валидации не пересекаются.

## Наблюдения по данным

- Train: 99 955 строк, 39 полигонов, 2010-2024 годы.
- Известный `primary_ndvi`: 30 520 строк.
- Private: 57 185 строк, 78 полигонов, 3 112 контрольных пропусков.
- В контрольной строке скрыты все динамические и вычисляемые признаки; остаются
  только идентификатор полигона, дата, тип культуры и флаг пропуска.
- 2 827 из 2 967 последовательностей контрольных пропусков имеют длину один день.
- Для половины контрольных точек ближайшее известное наблюдение находится не
  дальше трёх дней; для 90% — не дальше десяти дней.
- На всех размеченных строках train выполняется точное правило:
  `primary_ndvi = first_non_null(s2_ndvi, landsat_ndvi, modis_ndvi)`.

## Протокол проверки

1. Внутри каждого полигона и года случайно скрывается 15% известных значений —
   столько же примерно скрыто в private.
2. Перед построением признаков у контрольной строки удаляются все динамические
   признаки. Это исключает прямую утечку target и признаков текущего снимка.
3. Используются три варианта маскирования: seeds 13, 42 и 87.
4. Для оценки применяется `GroupKFold(5)` по `anon_polygon_id`: один полигон не
   может одновременно попасть в обучение и валидацию.
5. Метрика считается только по синтетически скрытым точкам.

## Модель

Сначала считается устойчивый baseline как blend среднего соседей, линейной
интерполяции и интерполированной климатологии. Затем
`HistGradientBoostingRegressor` предсказывает residual — поправку к baseline.

Признаки включают:

- три предыдущих и три следующих значения `primary_ndvi` и расстояния до них;
- отдельные соседние ряды Sentinel-2, Landsat и MODIS;
- EVI/NDWI, климатологию и погодные признаки из соседних дат;
- календарные признаки и тип культуры;
- статистику того же дня сезона в другие годы;
- медианы и доступность сенсоров на эту дату по другим видимым полигонам.

## Результаты

| Метод | OOF RMSE | Расчётный GapScore |
| --- | ---: | ---: |
| Среднее двух соседей | 0.09048 | 2.86 |
| Линейная интерполяция | 0.09179 | 2.46 |
| Гибридный baseline | 0.08861 | 3.42 |
| Гибридный baseline + ML residual | **0.06333** | **11.00** |

ML-подход снизил RMSE относительно гибридного baseline на 28.5%.

## Аномалии

Статус определяется по зафиксированной в постановке формуле:

`z = (primary_ndvi - climatology_mean) / climatology_std`.

Реализация воспроизводит `ndvi_zscore` с максимальным отклонением менее `1e-10`
и даёт 100% совпадение `status` на размеченных строках. Дополнительно отдельные
точки объединяются в периоды, рассчитывается confidence и формируется вероятная
причина: засуха, температурный стресс, уборка урожая либо непогодный фактор.

## Ограничения

- OOF-оценка имитирует механизм private, но скрытые ответы private недоступны;
  фактический GapScore определяется только платформой.
- Текущие причины аномалий являются интерпретируемыми гипотезами, а не
  подтверждённым агрономическим диагнозом.
- Для live-региона веб-сервису необходимо отдельно получать многолетнюю
  климатологию и погодные данные через GEE.
