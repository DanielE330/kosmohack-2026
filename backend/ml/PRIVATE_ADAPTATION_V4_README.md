# Submission v4: локальная self-supervised адаптация

`submission_ensemble_v4.csv` — экспериментальный кандидат поверх подтверждённого
v3 (`0.0699`). Он не заменяет и не перезаписывает v3.

## Идея

В `private_features.csv` кроме настоящих gaps есть видимые значения
`primary_ndvi`. Для каждого private-полигона алгоритм:

1. создаёт четыре непересекающихся набора pseudo-gaps среди видимых значений;
2. в каждом проходе скрывает только 15% значений;
3. получает для pseudo-gaps прогнозы всех компонентов v3;
4. обучает небольшой Ridge предсказывать локальную ошибку v3;
5. применяет ограниченную поправку к настоящим gaps того же полигона.

Настоящие 3 112 target не используются. Максимальная сырая поправка ограничена
`0.10`, а её вес зависит от количества калибровочных строк и не превышает
`0.33`.

## Валидация

Для каждой OOF-маски калибровка строилась только по другим seed. Все строки с
тем же `row_id`, что у проверяемых target, полностью исключались. Получено:

- v3 OOF RMSE: `0.062528`;
- adapted OOF RMSE: `0.061877`;
- улучшение: `0.000651`;
- улучшение на всех пяти GroupKFold-фолдах и всех трёх seed.

Это обоснованный кандидат, но его private RMSE можно узнать только после
отправки на платформу. Подтверждённый безопасный файл остаётся
`submission_ensemble_v3.csv`.

## Запуск

Из корня проекта:

```bash
python scripts/predict_ensemble_v4.py
```

Операция делает пять полных feature-engineering проходов и может занять
несколько минут. Результаты:

- `submission_ensemble_v4.csv`;
- `reports/private_adaptation_v4.json`;
- `reports/private_adaptation_v4.csv`.

Проверка воспроизводимой OOF-оценки:

```bash
python experiments/validate_private_adaptation.py
```
